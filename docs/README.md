# Docs

Usage guides for the tooling wired into these dotfiles. These files document
*how to use* a tool day-to-day; the configuration itself lives alongside the
relevant surface (`aliases`, `zsh/`, `bin/`, `tmux.conf`, `config/nvim/`).

> Markdown is excluded from RCM (`EXCLUDES="*.md"` in `rcrc`), so these docs
> stay in the repo and are never symlinked into `$HOME`.
